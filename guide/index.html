시작 전에 준비할 것

  • 💻 컴퓨터 — 맥(macOS 13 이상) 또는 윈도우 10·11. 늘 켜 둘 수 있는 컴퓨터가 좋아요
  • 🔌 충전기 연결 · 안정된 와이파이
  • 📱 휴대폰 — 로그인 인증·휴대폰 앱 연결에 써요
  • 🔑 컴퓨터 로그인 비밀번호 — 설치 중에 한 번 물어봐요
  • 📧 구글 계정 — 지메일·캘린더·드라이브 연결
  • 💳 Claude Max 결제 카드 — 본인 명의, 월 $100부터. Claude에 직접 결제해요
  • ⏱ 넉넉히 2~3시간 — 인터뷰 1시간, 설치·연결 1~2시간
1

셀프형 결제하기

  1. 브랜디움 메뉴 SETUP → 🧰 셀프형의 [셀프로 시작하기]
  2. 카카오·구글 계정으로 3초 가입·로그인
  3. 주문서에서 이름·휴대폰 확인 → 할인 쿠폰이 있으면 넣고 [적용]
  4. 환불 규정 동의 체크 → [주문하기] → 카드 결제(또는 계좌입금)
2

고객 키 받고 시작하기

  1. 결제가 끝나면 화면에 내 고객 키(KEY-OS-…)가 바로 나와요. [▶ 지금 시작하기]를 누르세요
  2. 계좌입금은 입금이 확인되면 마이페이지 → 내 주문에 키와 시작 버튼이 나타나요
  3. 고객 페이지에서 로그인 → 고객 키를 넣고 들어가요(링크로 오면 키가 미리 채워져 있어요)
3

STEP 0 · 튜토리얼 보기

퍼스널 OS가 무엇인지, 오늘 어떤 순서로 하는지 11장으로 보여 드려요. 다음 ›으로 넘기면 돼요.

💡 튜토리얼을 시작한 뒤부터는 환불이 70%로 바뀌어요(키트를 받기 전까지).

4

STEP 1~2 · 업무 질문과 AI 인터뷰

  1. STEP 1: 하는 일·자주 하는 업무를 고르고 짧게 적어요. 답이 짧으면 보충 질문이 몇 개 나와요
  2. STEP 2: AI 인터뷰 — 말하듯 편하게 답하세요. 휴대폰이면 키보드의 🎤 마이크로 말해도 돼요
  3. 인터뷰가 끝나면 AI가 제안서(부서·매니저·하는 일)를 1~2분 동안 만들어요
5

제안서 확인 · 확정

  1. 부서·매니저·하는 일을 읽어 보고, 점선 글자를 눌러 바로 고칠 수 있어요
  2. 화면 종류(본사형·매거진형·다이어리형 등)를 고르고, 매니저 이름을 정해요(비워 두면 호칭만)
  3. [이대로 확정]
6

회사 자료 올리고 · 설치 키트 받기

  1. (선택) 로고·직인·사업자등록증·자주 쓰는 양식을 올리면 키트에 함께 들어가요
  2. [⬇️ 내 설치 키트 만들고 받기] → 30초쯤 뒤 파일이 다운로드 폴더에 받아져요

⚠️ 셀프형은 설치 키트를 받은 뒤에는 환불되지 않아요. 받기 전에 한 번 더 물어봐요.

7

설치 — 맥

✅ 맥은 '터미널 한 줄'로 설치하세요. 받은 zip이나 설치 파일을 더블클릭하지 않아도 돼요. 이 방법은 맥의 보안 경고(아래 ⚠️)가 뜨지 않아요.

  1. 받은 키트 파일은 다운로드 폴더에 그대로 둡니다 (열지 않아도 돼요)
  2. ⌘(command) + 스페이스 → 터미널 입력 → 엔터
  3. 아래 한 줄을 복사해 터미널에 붙여 넣고 엔터 curl -fsSL https://mybrandium.com/tools/install.sh | bash
  4. 맥 비밀번호를 물어보면 입력 → 엔터. 입력해도 화면에 글자가 안 보이는 게 정상이에요
  5. Claude 로그인 창이 열리면 로그인 → Authorize(승인)
  6. 설치 단계가 차례로 지나가요(10분 안팎). 끝나면 바탕화면에 퍼스널 OS 앱이 생기고 화면이 열려요

⚠️ "열 수 없음" · "확인되지 않은 개발자" 창이 떠요 (설치 파일을 더블클릭했을 때)

zip을 풀고 설치.command를 더블클릭하면, 맥이 인터넷에서 받은 파일을 막으면서 [휴지통으로 이동] / [완료] 버튼만 있는 창이 뜰 수 있어요. 고장 난 게 아니에요.

  1. [휴지통으로 이동]은 누르지 마세요. [완료]를 눌러 창을 닫아요
  2. 가장 쉬운 방법: 위의 터미널 한 줄로 설치하세요. 이 경고 없이 설치돼요
  3. 꼭 더블클릭으로 하려면 → 화면 왼쪽 위 → 시스템 설정
  4. 왼쪽 목록에서 개인정보 보호 및 보안 → 오른쪽을 맨 아래까지 내려요
  5. 보안 칸에 "'설치.command'이(가) 차단되었습니다" 문구 옆 [그래도 열기]
  6. 맥 비밀번호(또는 Touch ID) 입력 → 다시 뜨는 창에서 [열기]
8

설치 — 윈도우

  1. 받은 zip 파일을 마우스 오른쪽 클릭 → 모두 압축 풀기
  2. 풀린 폴더에서 설치_윈도우를 더블클릭
  3. 파란 창 'Windows의 PC 보호'가 뜨면 추가 정보 → [실행]
  4. '이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?' → [예]
  5. Claude 로그인 → 자동 설치. 끝나면 바탕화면에 퍼스널 OS 바로가기가 생겨요
9

연결하기 · 휴대폰 연결

  1. 설치 창이 열어 주는 claude.ai 연결 화면에서 지메일·구글 캘린더·구글 드라이브·노션을 각각 [연결] → 같은 구글 계정으로 허용
  2. 휴대폰 연결 화면(큰 QR)이 뜨면: 휴대폰에 Tailscale 앱 설치 → 컴퓨터와 같은 계정으로 로그인 → QR 찍기
  3. 아이폰: 사파리 공유 버튼 → 홈 화면에 추가 · 갤럭시: 크롬 ⋮ → 홈 화면에 추가
  4. 갤럭시는 Tailscale 설정에서 '포함할 앱만 고르기'로 바꾸고 크롬·삼성 인터넷만 켜 주세요(삼성페이·은행 앱이 그대로 열려요)
10

첫 실습 → COMPLETE → 마무리 안내

  1. 퍼스널 OS 채팅창의 첫인사에 공식 실습 3가지가 나와요: 연결 확인 · "내가 누군지 설명해 봐" · 화면 바꿔 보기
  2. 세 가지가 끝나면 COMPLETE! 화면이 저절로 떠요
  3. 15초 뒤 브랜디움 마무리 안내(로그인 연장·기록 보관·구독·문의처)로 넘어가요. 여기까지 보면 끝!
FAQ

자주 막히는 곳

맥에서 '열 수 없음 / 휴지통으로 이동' 창이 떠요

[휴지통으로 이동]은 누르지 말고 [완료]. 그다음 터미널 한 줄로 설치하세요. 더블클릭으로 꼭 해야 하면 시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기] 순서를 따라 하세요.

터미널에 비밀번호를 쳐도 글자가 안 나와요

정상이에요. 보안 때문에 안 보일 뿐 입력은 되고 있어요. 다 치고 엔터를 누르세요.

Claude 로그인 창이 안 떠요 / 로그인했는데 넘어가지 않아요

브라우저 창이 뒤에 열렸을 수 있어요. 열린 창에서 Authorize(승인)를 눌렀는지 확인하세요. Claude 구독이 Max가 아니면 설치가 멈출 수 있어요(claude.ai → 설정 → 구독).

설치가 한 단계에서 15분 넘게 멈춰 있어요

창을 닫고 같은 터미널 한 줄(윈도우는 설치_윈도우)을 다시 실행하세요. 끝난 단계는 건너뛰고 이어서 진행해요.

윈도우에서 '파란 창'만 뜨고 실행이 안 돼요

추가 정보(작은 글씨)를 눌러야 [실행] 버튼이 나와요.

휴대폰에서 퍼스널 OS가 안 열려요

휴대폰 Tailscale이 켜져 있는지, 컴퓨터와 같은 계정인지 확인하세요. 컴퓨터가 잠자기 상태여도 안 열려요.

키트를 다시 받고 싶어요

같은 고객 키로 고객 페이지에 들어가면 언제든 다시 받을 수 있어요(추가 비용 없음).
